# Exercise animation corrections — September 9, 2026

The 50 previously held male sequences now use AI-reviewed selections. This updates 138 app SVGs; 12 existing endpoints remain byte-identical. All three frames still play in the app.

These previews render the selected SVGs on black in a 1–2–3–2 loop at 380 ms per frame. The app-ready assets and distribution provenance are committed; high-resolution masters, source copies, rejected drafts, normalized PNGs and full generation records remain in the retained local production workspace.

AI visual review is not qualified movement-expert approval. Small contour, equipment alignment and phase-spacing variations remain. Bear crawl and crab walk show partial forward-and-return steps, and cycling uses a limited pedal arc. Full female animation review was not part of this correction pass.

Exact prompt files are retained for 82 of the 150 selected frames; historical prompt/reference gaps for the other 68 are documented in the local ledger and were not fabricated.
